# 数据集摘要

> 本数据集是一个面向智能交通与道路安全监控的道路交通事故检测数据集，适用于事故自动检测、异常事件识别及相关目标检测算法研究。

## 摘要

该数据集共包含 **6,278 张**道路场景图像，统一尺寸为 **640 × 640 像素**，涵盖 **6 种**交通事故与正常场景类别：**汽车事故**（1,158 个标注）、**汽车碰撞**（1,587 个标注）、**非机动车碰撞**（750 个标注）、**非机动车事故**（1,461 个标注）、**汽车与非机动车碰撞**（1,607 个标注）以及**无事故正常场景**（1,509 个标注）。数据集总标注数达 **7,572** 个，部分图像包含多类别或多实例目标。

数据集按 **6,228 / 44 / 6** 的比例划分为训练集、验证集和测试集，并提供 **YOLO、VOC、COCO** 三种主流标注格式，可直接用于各类目标检测与分割模型的训练与评估。该数据集为道路交通事故检测、智能交通异常事件分析等方向提供了规模化的基准数据支撑。
